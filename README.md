# Franka Digital Twin

## Descrizione

Progetto di tesi magistrale dedicato alla progettazione e allo sviluppo
di un Digital Twin bidirezionale del braccio robotico Franka Emika FR3,
simulato in ambiente ROS 2 Jazzy e Gazebo.

## Obiettivi

- Rappresentare digitalmente lo stato del robot.
- Sincronizzare lo stato digitale con quello del robot simulato.
- Inviare comandi di movimento dal Digital Twin al robot.
- Valutare l'entanglement mediante la metrica ODTE.

## Tecnologie

- Ubuntu 24.04
- ROS 2 Jazzy
- Gazebo
- Python
- Git

## Stato del progetto

Fase iniziale: progettazione dell'architettura e organizzazione
del repository.
